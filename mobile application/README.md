# GOTRAJET — Mobile application

The GOTRAJET website packaged as a mobile app, in two forms built from the same code:

- **Installable web app (PWA):** open it in a phone browser, then use *Install* (or *Add to Home Screen* on iPhone). It opens full screen and works offline.
- **Native app (Android APK / iOS):** built with [Capacitor](https://capacitorjs.com). It installs like any other app, with its own icon and splash screen, and works offline.

**It is exactly the website.** `www/` (the app's content) is generated from `../dist` on every build, so every screen, text, language (FR / EN / AR, RTL), dark mode, map and flow is the website's own. Change the website in `../dist`, run `npm run build`, and the app follows. The app adds only a thin mobile layer:

| What the app adds | Where |
| --- | --- |
| Notch and home-indicator safe areas, no tap flash or double-tap zoom, no pull-to-refresh, bottom-sheet pop-ups on phones | `src/mobile.css` |
| Splash screen, status bar matching the screen header, Android back button (closes pop-ups and menus, goes back, press twice to exit), outside links (Google Maps) in the system browser, receipts and data export saved through the share sheet | `src/mobile.js` (native app) |
| Offline start and caching, "Install GOTRAJET" prompt, online/offline banner | `src/sw.js`, `src/mobile.js` (browser) |
| App icons (Android adaptive + round, iOS) and splash screens drawn from the website's logo | `scripts/make_icons.py` |

## Commands

Run them inside this folder (`cd "mobile application"`). First time: `npm install`.

| Command | What it does |
| --- | --- |
| `npm run build` | Rebuilds `www/` from the website (`../dist`). |
| `npm run serve` | Builds, then serves the web app at http://127.0.0.1:4174. Open it in Chrome, use the device toolbar (phone view) or install it. |
| `npm run sync` | Builds and copies the app into the Android and iOS projects. |
| `npm run apk` | Builds an Android APK into `build/GOTRAJET.apk` (needs JDK 21 and the Android SDK). |
| `npm run android` | Builds, syncs and opens Android Studio (run on a phone or emulator from there). |
| `npm run ios` | Builds, syncs and opens Xcode (macOS only). |
| `python tests/check_app.py` | Checks the app against the website (needs `npm run build` first). |

### Install on an Android phone

1. `npm run apk`, then copy `build/GOTRAJET.apk` to the phone (USB, Drive, email…).
2. Open it on the phone and allow *Install unknown apps* when asked.

Or connect the phone with USB debugging on: `adb install -r build/GOTRAJET.apk`.

`npm run apk` needs **JDK 21** (`JAVA_HOME`): Capacitor 8 does not build with JDK 17. Install [Temurin 21](https://adoptium.net/temurin/releases/?version=21), or use Android Studio's own JDK. The Android SDK is found through `ANDROID_HOME`, or in `%LOCALAPPDATA%\Android\Sdk` where Android Studio puts it.

### iPhone

- Web app: open the served address in Safari → Share → *Add to Home Screen*. (A phone needs HTTPS to install it, so use the deployed site, not `127.0.0.1`.)
- Native app: needs a Mac with Xcode. Copy this folder to the Mac, then run `npm install` and `npm run ios`, choose your team in *Signing & Capabilities*, and press Run.

## Demo data or real accounts

- **Default (bundled):** the app contains the website's files and runs offline with the same local demo data as `../dist/index.html` opened directly. Data stays on the phone.
- **Real backend:** point the app at the deployed GOTRAJET server (`python backend/run.py` locally, or your domain in production). The app then opens that address, exactly like the website served by the backend, with real accounts, payments and messages.

  ```powershell
  $env:GOTRAJET_SERVER_URL = "https://your-domain.example"
  npm run apk          # or npm run android / npm run ios
  ```

  For a quick test on a phone on the same Wi-Fi, run the backend on `0.0.0.0` and use `http://<computer-ip>:8000` (plain HTTP is allowed only when the address starts with `http://`). Remove the variable and rebuild to return to the bundled app.

## Publishing (not done yet)

- **Google Play:** create a signing key, then in Android Studio *Build → Generate Signed App Bundle* (`.aab`). Store icon: `resources/play-store-icon-512.png`. The app id `ma.gotrajet.app` cannot change after the first upload, so confirm it before publishing.
- **App Store:** an Apple Developer account and a Mac; archive from Xcode. Icon: `resources/icon-1024.png` (already in the Xcode project).
- **Web app:** deploy `www/` (or keep deploying `../dist` and add `css/mobile.css`, `js/mobile.js` and `sw.js` from `www/`) on HTTPS.

The version shown in the stores is set in `android/app/build.gradle` (`versionCode`, `versionName`) and in Xcode (*General → Identity*).

## Changing icons or the splash screen

The icons and splash screens come from `../dist/assets/favicon.svg`. After changing the logo, run `python scripts/make_icons.py` (needs Python Playwright with Chromium, and Pillow, as for the website's tests).
